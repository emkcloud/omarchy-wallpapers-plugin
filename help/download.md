# Download

These settings apply to every future installation. Wallpapers already downloaded
are not touched.

- **Default resolution** — which variant is downloaded when a wallpaper is
  available in several formats. Only 2K is available for now; 4K and 8K are shown
  disabled until they ship. If the chosen resolution does not exist, the highest
  available one is used.
- **Random wallpapers per theme** — how many wallpapers the Shuffle action
  installs for the selected theme (1-50, default 5). A different random seed is
  used on every single run of Shuffle.
- **Parallel downloads** — how many files are downloaded at the same time
  (1-12, default 8). Higher values are faster but heavier on the network, the
  disk and the remote server as well.
- **Max local files** — maximum number of wallpaper files kept on disk
  (1000-5000, default 2500). The cap applies to the bulk **Install all** action;
  installing wallpapers by hand is always allowed.
- **Max disk size (GB)** — maximum disk space the installed wallpapers may use
  (1-50, default 3). Like the file cap, it applies to the bulk **Install all**
  action and to Shuffle, never to manual installs.

**Restore defaults** in the right column resets every value to its default.
