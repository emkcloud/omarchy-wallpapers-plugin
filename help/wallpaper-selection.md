# Wallpapers

The grid shows every wallpaper of the selected theme. Each tile carries the
country code in accent and the name over the thumbnail. The installed dot sits
in the top-right corner, a **DEFAULT** pill marks the current background, a
**★** marks a favourite, and a checkbox in the top-left drives the multi-select.

Click a tile (or press enter) to open the fullscreen preview. Press space to
tick the cursor tile without leaving the grid. **Select all** ticks every row
the grid is currently showing, so an active search narrows the selection. When
at least one tile is checked, **Install** and **Uninstall** act on the whole
selection.

## Favorites

Press `f` (or `m`) to star the wallpaper under the cursor, in the grid and in
the fullscreen preview. With some tiles checked, `f`/`m` act on the whole
selection: if every checked wallpaper is already starred the group is cleared,
otherwise the whole group is starred — so **Select all** followed by `f` stars
everything (or unstars everything when they already are). Favourites are global:
the same wallpaper keeps its star in every theme, because the file is the same
and only the colours change. The picker gains a **Favorites** entry that
narrows the grid to your starred wallpapers, and combining it with the search
works as usual. On Custom install a **Favorites** card installs (or removes)
exactly the starred wallpapers the open theme has. See the Favorites topic for
the full picture.

## Simple search

To find a wallpaper, use the search bar on this screen. The search
is literal, not semantic, but it still helps you find it quickly:
type a word such as **italy** and the grid narrows to the matching wallpapers.

## Collections

The picker to the left of the search bar narrows the grid to a single
collection of the open theme instead of everything at once. The default
**All collections** shows every wallpaper; pick one (for example the shelters
set while browsing a theme whose other collection is countries) and the grid,
the **Select all** button and the counts follow it. The collection filter and
the text search combine, so a collection can be searched within.

## Keyboard

| Key | Action |
|---|---|
| h / j / k / l | move the selection |
| arrows | move the selection |
| pageup / pagedown | jump a page |
| enter | open the preview |
| space | check / uncheck the cursor tile |
| f / m | star / unstar the cursor tile, or the whole selection |
| i | install the selection, or the cursor tile |
| u / del | uninstall the selection, or the cursor tile |
| d | set the cursor tile as the theme default |
| / | search by name or code |
| s | open setup |
| q / x | close the window |
| esc | back to the themes |

## Large preview

If the thumbnails are too small to judge a wallpaper, press enter on a tile to
open it in the preview and install it from there in large format.
