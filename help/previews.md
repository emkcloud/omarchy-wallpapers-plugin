# Previews

If the thumbnails in the grid are too small to judge a wallpaper properly, press
enter on one of them to open the preview. You can then scroll through the
wallpapers one at a time in large format and install the one you want directly
with the key shown below.

The preview fills the card with the full-resolution wallpaper. The header
repeats the theme, collection and name, plus the file size; a resolution pill
and a **Download** button sit on the right.

Double click the image (or press `d`) to make the wallpaper the theme default:
the file is installed first when needed, and the same gesture clears the default
back to the theme's own background. **Download** saves the original file to a
folder you pick with the system file chooser. The path pill in the bottom-left
shows where the installed copy lives, and the filmstrip in the bottom-right walks
the neighbouring wallpapers.

## Keyboard

| Key | Action |
|---|---|
| h / j / k / l | previous / next wallpaper |
| arrows | previous / next wallpaper |
| pageup / pagedown | previous / next wallpaper |
| enter / space / i | install the wallpaper |
| d | toggle the theme default |
| u / del | uninstall the wallpaper |
| q / x | close the window |
| esc | back to the grid |

## Download file

To use a wallpaper in a custom way, you can save it straight to your local
computer in a folder of your choice. Press **Download** and you will be asked
to pick a folder where to save the file.
