# Custom install

Custom install narrows an installation to what you want, without the whole
theme or a random sample. Open it from the themes list: select a theme and
choose **Custom Install**, or press `c` while the row is selected.

The screen keeps the plugin's three-column shape. The left pane
shows a 3×3 grid of the theme's previews with its info overlaid — name,
collections / wallpapers / installed, description and palette. The right pane
lists the install choices, and a switch at the bottom controls the default
wallpaper.

## What to install

- **Full collections** — the whole theme, every collection at once.
- **Full …** — one collection, e.g. **Full Countries**.
- **Shuffle (N)** — N random wallpapers of the theme, set in Setup.
- **Select only** — pick the wallpapers by hand on the grid.

Move with the arrows (or h / j / k / l), then run the highlighted card with
enter, space or `i`. A single click only selects. **Install** runs the
highlighted choice; **Uninstall** removes it — the whole theme for **Full
collections**, or just that collection for a **Full** card. Caps from Setup
apply.

## Default wallpaper switch

**Set a random wallpaper as default when done** picks a random theme wallpaper
once the install finishes and makes it the default. It is on by default and
saved with the other settings. `Tab` moves between the cards and the switch.

## Browse

Press `b` to open the theme's wallpaper grid instead: it is the same grid as the
Wallpapers screen, so you can inspect and install single wallpapers. When a
collection card is highlighted, the grid opens already narrowed to that
collection. `Esc` there returns to Custom install with its state intact.

## Keyboard

| Key | Action |
|---|---|
| h / j / k / l | move the selection |
| arrows | move the selection |
| enter / space | run the highlighted choice |
| i | install the highlighted choice |
| u | uninstall the highlighted scope |
| b | browse the theme's grid |
| tab | switch between the cards and the switch |
| s | open setup |
| ? | open this guide |
| q / x | close the window |
| esc | back to the themes |
