# Themes

The first screen lists every theme in the remote collection. Each row shows a
preview, the theme name, and how many collections and wallpapers it contains. A
dot summarises the local state: filled means every wallpaper is installed,
dimmed means a partial install, and hollow means the theme is remote-only.

Select a row to open its wallpaper list, or use the bulk actions on the right to
install or remove a theme. A theme whose Omarchy counterpart is not
installed shows a **Theme not found** badge and hides the install
actions.

## Available themes

- **Catppuccin** — soothing pastel accents over deep dark backgrounds.
- **Gruvbox** — retro palette with warm earthy browns and muted greens.
- **Matte Black** — matte black backgrounds with a strong orange accent.
- **Nord** — cold, muted blue-gray tones with crisp arctic contrast.
- **Osaka Jade** — a fresh jade green palette with warm highlights.
- **Solitude** — minimal monochrome near-black backgrounds with soft grays.
- **Tokyo Night** — deep blue backgrounds with cyan and purple neon accents.

## Wallpaper manager

Every theme is managed from this screen. Select a theme and choose install or
uninstall to add or remove the whole collection: all the wallpapers
that belong to that theme are installed, or removed, together. A large
collection can take several minutes, but you can stop it at any time
by pressing esc.

## Shuffle selection

If you would rather not install a whole collection, let the
manager choose for you. Press f to install a random sample of the selected theme,
five wallpapers by default (configurable in Setup), so you can try its look
before committing to the complete collection.

## Keyboard

| Key | Action |
|---|---|
| h / j / k / l | move the selection |
| arrows | move the selection |
| pageup / pagedown | jump a page |
| enter / space | open the selected theme |
| i | install all wallpapers of the selected theme |
| u | uninstall all wallpapers of the selected theme |
| f | shuffle in a random sample |
| r | refresh the list |
| / | search the themes |
| s | open setup |
| ? | open this guide |
| q / x | close the window |
| esc | close the window |

## Custom install

If you do not want to install every wallpaper of the selected theme, and
shuffle is not enough, there are two ways to narrow it down. Use **browse** to
open the theme and pick the wallpapers by hand, one at a time. Or use **Custom
Install** to choose one or more collections of that theme to install.
