# Default wallpaper

A wallpaper installed locally can become the **default** of its theme: the image
Omarchy shows for that theme, and the one it returns to whenever the theme is
re-applied. There are three ways to set it.

## 1. Omarchy background switcher

Install the wallpapers first, then open Omarchy's switcher with
**Super + Ctrl + Space** and pick the image. It lists every background of the
current theme, including the plugin ones, so the two collections stay in sync.

## 2. The `d` key in the plugin

Open a theme's wallpaper grid, or a single wallpaper in the preview, and press
**d** on the one you want. The file is installed first when needed and set as the
theme default; pressing **d** again on the same wallpaper clears it, falling back
to the theme's own background.

## 3. Automatic rotation

Turn on **Automatic rotation** in Setup to have the plugin change the default on
its own at the interval you choose, cycling through the theme's wallpapers. See
*Automatic rotation* in this guide for the details.
