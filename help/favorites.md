# Favorites

A favourite is a wallpaper you starred to find it again quickly, in any theme.
Because the theme only changes the colours — the file itself is the same — a
starred wallpaper keeps its star when you switch theme, and can be installed
into every theme from a single card.

## Star a wallpaper

In the wallpaper grid or in the fullscreen preview, press `f` (or `m`) on the
wallpaper under the cursor. A **★** appears on its tile. Press the same key
again to remove it. Starring is global: it is not tied to the open theme.

To star several at once, check them on the grid (space, or **Select all**) and
press `f`/`m`: the whole selection is starred. If every checked wallpaper is
already a favourite, the same keys clear the whole group instead — so **Select
all** then `f` stars everything, and repeating it removes them all. Like an
install, starring a selection clears the checks when it is done.

## Browse your favourites

The collection picker on the Wallpapers screen gains a **Favorites** entry
once you have at least one. Pick it to narrow the grid to your starred
wallpapers, in whatever theme you are browsing; the search field still composes
with it.

## Install them in another theme

Open **Custom install** on a theme and pick the **Favorites** card: it installs
exactly the starred wallpapers that theme has, skipping the ones it does not
offer (a theme without the *machines* collection simply has fewer). The same
card's **Uninstall** removes them from that theme. The limits in Setup apply to
this card, like to the collection cards.

## Keyboard

| Key | Action |
|---|---|
| f / m | star / unstar the cursor wallpaper |
